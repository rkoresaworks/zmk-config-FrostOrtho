# 初期キーマップ
初期設定はJIS配列、オートマウスレイヤーありとなっています。  
ロータリーエンコーダーはどのレイヤーでも音量のUP/DOWNになっています。  

## レイヤー0
デフォルトのレイヤー  
「⇧Z」など2種類記載されているキーは、ModTapです。  
「⇧Z」の場合、短押しではZが入力され、長押しでは⇧（Shift）が入力されます。  
- 数字：押している間各レイヤーに切り替わる
- ⇧：Shift  
- ＾：Control
- ↵ ：Enter
- LANG1：ひらがな
- LANG2：半角英数字

## レイヤー4
Bluetoothの設定や切り替えをする  
最大5台の端末にてマルチペアリングが可能です。キーボードの電源をオンにしたのちBT_SEL_0 ～ BT_SEL_4のいずれかを押して端末と接続してください。
- BT_CLR：選択中のBluetooth設定を初期化する
- BT_CLR_ALL：5個すべてのBluetooth設定を初期化する

## レイヤー6
マウスレイヤー  
組み立て済み品の場合オートマウスレイヤーが有効になっているため、トラックボールを動かした後にU、I、Oを押すとMB1、MB2、MB3になります。  
U、I、O、Shift、Contrl、Alt以外のキーを押すとキー入力モードに戻ります。  
- MB1：左クリック
- MB2：右クリック
- MB3：中央クリック

## 設定レイヤーの呼び出し
左親指のSpaceとBSの同時押しで設定レイヤー（Bluetooth切替）に入ります。Mac・Windows共通です。左下のESCはESC単独のキーです。

## Windowsレイヤー
BTプロファイル3（設定レイヤーのO）を選ぶとWindows用レイヤーが自動で有効になり、他のプロファイルではMac用に戻ります。  
プロファイルは `FrostOrtho_R.conf` の `CONFIG_FROSTORTHO_WIN_BT_PROFILE` で変更できます。USB接続時も選択中のBTプロファイルに従います。

Windows側は日本語キーボード（106/109）設定を前提としています。  
IME切替のため、Microsoft IMEの設定で「無変換キー: IME-オフ」「変換キー: IME-オン」を割り当ててください。

Mac用レイヤーとの差分だけをレイヤー8以降に持ち、Mac用レイヤーと同時に有効になった時だけ重なります。
- レイヤー8：土台。CmdとCtrlを入れ替え（親指=Ctrl、Ctrlだった箇所とS+D・K+Lコンボ=Win）、親指タップは無変換/変換、右下段のSpace=Win
- レイヤー9/10：数字・記号をJIS配列用に補正
- レイヤー11：AeroSpace系をWindows標準機能へ置換
  - Alt+1～5 → Win+1～5、Alt+0 → Win+D
  - ウィンドウ結合 → Win+矢印（スナップ）、Win+Z（スナップレイアウト）
  - Cmd+Shift+4 → Win+Shift+S
- レイヤー14：画面ロックをWin+Lへ
- レイヤー15：Ctrl+矢印 → 仮想デスクトップ移動（Win+Ctrl+←/→）、Win+Tab、Ctrl+Alt+Tab
- レイヤー16/17：AML・スクロール中のLED点灯とスクロール方向用

エンコーダーとトラックボールのスクロール方向は、Macのナチュラルスクロールと同じ向きになるよう逆転しています。
